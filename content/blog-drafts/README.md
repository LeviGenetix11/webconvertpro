# Blog drafts

Write new posts here as `.md` files. Start from `../templates/blog-post.md`.

**To publish:** move the file into `src/blog/posts/` and name it `YYYY-MM-DD-short-keyword-slug.md`. The part after the date becomes the URL: `2026-11-04-google-business-profile-checklist.md` publishes at `/blog/google-business-profile-checklist/`.

Then run `npm run build` to check it, commit, and push. Netlify deploys it.
