# Content folder

Everything here is **working material**. Nothing in this folder is published. The website itself lives in `/src`.

| Folder | What goes here |
|---|---|
| `seo/` | Keyword map, SEO checklists, blog content calendar |
| `blog-drafts/` | Posts in progress. When one is ready, move it to `src/blog/posts/` |
| `social/` | Content pillars, calendar, captions, scripts for Instagram, Facebook, TikTok |
| `ads/` | Meta and Google ad copy, targeting, UTM links, creative files |
| `outreach/` | Cold call and DM scripts, Outscraper settings, lead lists (not committed to Git) |
| `brand/` | Voice, colours, fonts, offers and pricing: the source of truth |
| `templates/` | Copy these to start a new blog post, social post, ad or demo site |

## The loop

1. **Pick a keyword** from `seo/keyword-map.md` and the next topic in `seo/content-calendar.md`.
2. **Write the post** from `templates/blog-post.md` into `blog-drafts/`.
3. **Run the checklist** in `seo/seo-checklist.md`.
4. **Publish:** move the file to `src/blog/posts/`, commit, and Netlify deploys it.
5. **Repurpose it** into 3 to 5 social posts and one ad (see `social/content-pillars.md`).
6. **Tag every link** you post with UTM parameters (see `ads/utm-guide.md`).
7. **Review monthly:** Search Console for rankings, Netlify for form submissions, Analytics for sources.
