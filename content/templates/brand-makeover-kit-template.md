# Contractor Brand Makeover Kit — fulfillment template

Internal template for every `/branding-preview/` submission. Never publish this file itself. Everything produced from this template is a conceptual direction, not a finished deliverable — label it that way every time it's sent, per `content/brand/brand.md`'s proof rules.

---

## 1. Existing brand assessment
If they uploaded a logo or gave a website: 2–3 sentences on its current state. If they have nothing yet, say so plainly rather than inventing a "before."

## 2. Logo assessment / direction
If existing: specific, concrete feedback (legibility at small size, colour count, whether it works in one colour). If none exists: 1–2 initial directions based on their stated style/industry.

## 3. Typography recommendations
Suggest a heading + body pairing appropriate to their stated style (e.g. bold/modern vs. traditional/established) — name real, licensable fonts (Google Fonts is the safe default), don't invent font names.

## 4. Colour palette recommendations
2–4 colours max, built from their stated preference if given. Show actual hex values, not vague names.

## 5. Visual consistency assessment
Only if they have an existing presence to assess (current site, social, van) — otherwise mark not applicable.

## 6. Website branding recommendations
How the above palette/type would apply to their homepage — one or two sentences, not a full redesign.

## 7. Business card concept
A short written description of a concept direction (layout, what's on it) — produce an actual mockup only if time allows; don't claim one exists if it doesn't.

## 8. Vehicle branding direction
One or two sentences on how the mark/colours would translate to a vehicle wrap — direction only, not a finished wrap design.

## 9. Social media branding direction
How post templates would use the palette/type consistently.

## 10. Brand messaging recommendations
One suggested line or two that reflects their stated primary branding objective — not a full copy deck.

## 11. Recommended next steps
Close by linking to `/branding/` for the actual paid branding packages, per `references/cta.md`. Never promise a complete, final brand identity is included free — this kit is a direction, not the deliverable.
